=====================================================
 파리의 견습생 : 1789~1815  선생님용 정답과 해설
=====================================================
■ 한눈에 보기
  주인공: 파리 생탕투안 거리 '뒤부아 인쇄소'의 열네 살 견습생 (피에르 / 마들렌 중 고름)
  흐름: 장마다 사건을 직접 겪거나(바스티유·바렌·밤의 파리·러시아) 들은 이야기로 떠올리고(회상 장면),
        인쇄소로 돌아와 '신문 1면 머리기사'를 골라 찍습니다. 1면 6장이 모이면 26년의 흐름이 완성돼요.
  시간: 약 45분 (프롤로그 4분 · 1장 7분 · 2장 6분 · 3장 8분 · 4장 7분 · 5장 6분 · 6장 5분 · 에필로그 2분)
  난이도: 중학생 기준 낮음. 틀려도 다시 조사하면 계속 도전, 힌트(H) 10개 + 퀴즈로 힌트 추가.

■ 꾸민 이야기와 실제 역사 (게임 시작 때 안내 카드로 알려 줌)
  꾸민 인물: 주인공, 뒤부아 아저씨, 폴(단짝 → 의용군 → 러시아 원정에서 실종), 클레르(귀족 소녀)
  실제 인물(대사는 꾸밈): 시에예스, 바이이, 드루에, 로베스피에르, 데물랭, 나폴레옹, 조제핀, 교황 비오 7세, 다비드
  전해지는 이야기: 백일천하 신문 머리기사 변화('식인귀' → '황제 폐하')는 실제 기사가 아니라 풍자로 전해지는 이야기임을 게임 안에서 밝힘
  회상 장면: 주인공이 직접 보지 못한 사건(테니스코트의 서약, 루이 16세 처형, 대관식, 워털루)은
            화면 전체가 옛날 사진 색으로 바뀌는 '회상'으로 처리

-----------------------------------------------------
■ 프롤로그 · 1789년 봄 (구체제의 모순, 삼부회, 테니스코트의 서약)
  1. 빵집 주인에게 빵 사기 → 빵값 폭등(흉년), 세금 불공평 / 가죽 앞치마(감시에 한 번 들켜도 괜찮음)
  2. 인쇄소 벽 그림 = 사료 카드 「제3신분이 짐을 지다」
  3. 세 신분 피라미드 다이얼  정답: 맨 위 성직자 / 가운데 귀족 / 맨 아래 평민(농민·상공업자)
  4. 활자 상자 → 시에예스 「제3신분이란 무엇인가?」 (전부다 / 아무것도 아니었다 / 무엇인가가 되는 것)
     다락 → 숨은 전단지 ① 삼부회 진정서
  5. [회상] 테니스코트: 대표 셋에게 단서 (국민 의회 선언 / 회의장 폐쇄 / 헌법이 목표)
     바이이의 맹세  정답: "헌법을 만들 때까지 결코 흩어지지 않는다"  → 사료 카드 다비드 「테니스코트의 서약」
  ※ 신분별 표결(1신분 1표) 대 머릿수 표결 갈등은 폴의 대사로 설명

■ 1장 · 1789년 7월 14일 바스티유 (혁명의 시작, 인권 선언)
  1. 연기(좌우로 움직임)와 떨어지는 돌(바닥 무늬)을 피해 도개교 → 성문 조사
  2. 감방 세 곳: 4명 + 2명 + 1명  → 수비대 상자 자물쇠  정답: 7
  3. 공격한 까닭  정답: 화약과 무기를 얻으려고 (그리고 왕의 전제 권력의 상징)
  4. 금 간 벽 → 화약 창고(어둠): 화약 통, ★사료 카드 '바스티유의 금서'(로크·몽테스키외·루소, 계몽사상), 숨은 전단지 ②
  5. 인쇄소: 8월 4일 봉건적 특권 폐지 설명 → 인쇄 타이밍(8번 성공) → 인권 선언 빈칸
     정답: 자유 / 평등 / 주권   → 사료 카드 르 바르비에 「인간과 시민의 권리 선언」
     (올랭프 드 구주 「여성과 여성 시민의 권리 선언」으로 한계도 짚음)
  6. 1면 ①  정답: "바스티유 함락! 시민이 요새를 무너뜨리다"  (오답 = 소문 / 관계없는 기사)

■ 2장 · 1791년 6월 바렌 사건 (입헌 군주제 → 공화정)
  1. 마차 추격 (75초, 닿으면 성공. 놓치면 마차에 다시 말 걸기) / 양 떼·건초 수레 피하기
  2. 드루에에게 아시냐 지폐(왕의 옆얼굴) → 승객 다섯 살펴보기
     정답: 하인 옷의 키 큰 남자 (손이 하얗고 고움, 금 시곗줄)
  3. 마구간 건초 → 숨은 전단지 ③ '왕이 도망쳤다!'
  4. 인쇄소 벽보 순서  정답: 1791 헌법(입헌 군주제) → 오스트리아와 전쟁(1792.4) → 8월 10일 왕궁 습격 → 공화국 선포(1792.9.22)
     → ★사료 카드 '라 마르세예즈'
  5. 1면 ②  정답: "왕의 도주, 바렌에서 막히다 · 프랑스는 공화국으로"
  6. 폴이 의용군으로 떠남

■ 3장 · 1793~1794년 (국민 공회, 공포 정치, 테르미도르)
  1. [회상] 혁명 광장(1793.1.21 루이 16세 처형): 지롱드파·자코뱅파 의원 이야기
     정답: 왕의 처형을 강하게 주장하고 권력을 잡은 쪽 = 자코뱅파
     (뒤부아의 설명: 공안 위원회, 혐의자 체포·처형, 최고 가격제, 남자 보통 선거 헌법)
  2. 밤의 파리: 감시위원회 벽보 = 혐의자법(1793.9)
     고발장 세 장 중 '증거'  정답: 세 번째 (장부 첨부)  → 소문과 증거 가려내기
  3. 떨어진 원고 → 숨은 전단지 ④ 데물랭 「늙은 코르들리에」(관용을 주장, 1794.4 처형)
  4. 클레르 선택 (어느 쪽이든 진행됨)
     · 돕는다: 순찰대 시야(빨간 칸)를 피해 동쪽 관문 마차까지 → 클레르의 리본, 4장·에필로그에서 다시 만남
     · 돕지 않는다: 혼자 떠남 → 에필로그에서 '감옥에 갇혔다가 테르미도르 뒤 풀려났다'는 편지
  5. 1면 ③  정답: "테르미도르 9일, 로베스피에르 몰락 · 공포 정치 끝나다" (→ 총재 정부 설명)

■ 4장 · 1799~1804년 (나폴레옹의 등장)
  1. 우편함: 폴의 편지(이집트 원정 1798, 로제타석) + 사료 카드 다비드 「알프스산맥을 넘는 나폴레옹」(선전 그림임을 짚음)
  2. 브뤼메르 쿠데타(1799, 통령) 설명 → 나폴레옹 법전 다이얼
     정답: 법 앞의 평등 = 성과 / 재산 보호 = 성과 / 종교의 자유 = 성과 / 아내의 복종 = 한계
  3. [회상] 노트르담 대관식(1804.12.2): 교황·나폴레옹·조제핀 → 다비드
     정답: "황제의 힘은 교회가 아니라 자기 자신(과 국민)에게서 나온다"
     기둥 뒤 → 숨은 전단지 ⑤ 대륙 봉쇄령(1806)
  4. 1면 ④  정답: "나폴레옹, 스스로 황제의 관을 쓰다"  (오답 '교황이 씌웠다'는 흔한 오개념)

■ 5장 · 1812년 러시아 원정 (나폴레옹의 몰락 시작)
  1. 추위: 시간이 지나면 하트 -1 → 모닥불 조사로 회복 / 버려진 마차 → 털장갑(덜 추움)
  2. 부서진 짐마차 → 숨은 전단지 ⑥ 대육군 제29호 공보('황제 폐하의 건강은 이보다 좋을 수 없다')
  3. 베레지나강 다리: 40초 안에 건너편 깃발 조사 (다리 위 구멍 조심) → 폴 실종, 폴의 모자
     → 사료 카드 미나르 도표 (42만 → 1만)
  4. 1면 ⑤  정답: "러시아 원정 실패, 대육군이 눈 속에서 무너지다" (정부 공보와 대비)

■ 6장 · 1815년 (백일천하, 워털루, 빈 회의)
  1. 신문 가판대 순서  정답: 식인귀(3.1) → 코르시카 괴물(3.7) → 찬탈자(3.10) → 황제 폐하(3.20)  ※ 전해지는 이야기
  2. 전령 → [회상] 워털루: 장교에게 명령서 → 90초 안에 농가 병사·정찰병에게 전달 (진흙에서 느려짐, 기병대 피하기)
     동쪽에서 온 군대  정답: 프로이센군 (블뤼허)
  3. 왕당파 신사: 빈 회의 원칙  정답: 혁명 이전의 왕조와 국경으로 되돌린다 (정통주의, 메테르니히)
  4. 1면 ⑥  정답: "워털루 전투 · 빈 회의, 유럽을 혁명 이전으로"

■ 에필로그 (빈 체제 이후의 유럽 암시)
  빈 체제(메테르니히, 자유주의·민족주의 억압) → 1830년 7월 혁명 · 1848년 2월 혁명 →
  민족주의와 국민 국가: 이탈리아 통일(1861, 사르데냐·카보우르·가리발디), 독일 통일(1871, 프로이센·비스마르크)
  숨은 전단지 6장을 모두 모았으면 특별 호외 '견습생이 본 혁명 26년'

■ 수업 활용 팁
  · 두 차시로 나누기: 1차시 프롤로그~3장(약 25분), 2차시 4장~에필로그(약 20분)
  · 신문 1면 6장을 학습지의 '연표 채우기'와 연결 (학습지 별도 제공)
  · 토론 거리: 클레르를 도울 것인가(공포 정치 속 개인의 선택), 나폴레옹은 혁명의 계승자인가 배신자인가,
    선전 그림(알프스)·정부 공보(29호)·신문의 말 바꾸기(백일천하) → 사료와 언론을 비판적으로 읽기
